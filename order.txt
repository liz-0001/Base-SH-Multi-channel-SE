# grouping-inter 分支运行指令

本分支默认启用以下模块：

```text
order-wise SH grouping
+ high-low mutual guidance
+ adjacent-order interaction
```

所以训练、推理、测评命令里不需要再写 `--enable_order_grouping`、`--enable_adjacent_interaction`、`--enable_high_low_guidance` 这类模块开关。

---

## 1. 训练指令

```bash
python -u train.py   --gpus 0,1,2,3   --loss_type mse_sisdr_stft   --sisdr_weight 0.01   --stft_weight 0.5   --num_epoch 100   --batch_size 8   --num_worker 8   --lr 1e-3   --model_dir model_grouping_inter_mse_sisdr_stft_8mic
```

### 训练参数解释

`python -u train.py`

启动训练脚本，`-u` 表示不缓存输出，训练日志和进度条会更及时显示在终端。

`--gpus 0,1,2,3`

指定训练使用的 GPU 编号。你的 4 张 2080Ti 可以这样写。如果只想单卡训练，可以写 `--gpus 0`。

`--loss_type mse_sisdr_stft`

使用组合 loss：时域 MSE + SI-SDR loss + STFT 幅度谱 loss。

`--sisdr_weight 0.01`

SI-SDR loss 的权重。这里设置较小，避免 SI-SDR 项压过 MSE 主损失。

`--stft_weight 0.5`

STFT loss 的权重，用来加强频域幅度谱约束。

`--num_epoch 100`

最大训练轮数。代码里有 early stopping，如果验证集长期不提升，会提前停止。

`--batch_size 8`

global batch size。4 张 2080Ti 时可以先用 8；如果显存不够，改成 4。

`--num_worker 4`

DataLoader 读取数据的 worker 数。服务器 CPU 资源足够时可以用 4 或 8。

`--lr 1e-3`

初始学习率。当前训练脚本会根据验证集表现调整学习率。

`--model_dir model_grouping_inter_mse_sisdr_stft_8mic`

模型权重、训练曲线、每轮指标和 `run_config.json` 的保存目录。

---

## 2. 推理指令

```bash
CUDA_VISIBLE_DEVICES=0 python -u inference.py   --modelpath model_grouping_inter_mse_sisdr_stft_8mic   --model_name model_best.pth   --test_name mic_8   --mic_prefix mic   --prediction_path /data/lizhe/SH_data/Mic8_2s_gpurir/predictions_grouping_inter_mic_8
```

### 推理参数解释

`CUDA_VISIBLE_DEVICES=0`

推理只使用第 0 张 GPU。推理通常单卡即可。

`python -u inference.py`

启动推理脚本，只生成增强后的 wav，不在推理阶段计算 PESQ/STOI/SDR/SI-SDR。

`--modelpath model_grouping_inter_mse_sisdr_stft_8mic`

权重所在目录。

`--model_name model_best.pth`

读取训练过程中验证集最优的权重文件。

`--test_name mic_8`

使用 8 麦测试集，对应数据路径中的 `test_mic_8` 和 `wav_scp_test_mic_8.txt`。

`--mic_prefix mic`

RIR/MIC 文件名前缀。你的测试 MIC 文件是 `mic_160_0.1.npy` 这种格式，所以这里必须写 `mic`。

`--prediction_path /data/lizhe/SH_data/Mic8_2s_gpurir/predictions_grouping_inter_mic_8`

增强语音输出目录。推理生成的 wav 会保存在这里。

## 3. 测评指令

```bash
CUDA_VISIBLE_DEVICES=0 python -u evaluation_fixed.py   --dataset_root /data/lizhe/SH_data/Mic8_2s_gpurir   --prediction_path /data/lizhe/SH_data/Mic8_2s_gpurir/predictions_grouping_inter_mic_8   --test_name mic_8   --modelpath model_grouping_inter_mse_sisdr_stft_8mic   --model_name model_best.pth   --profile_model   --save_dir model_grouping_inter_mse_sisdr_stft_8mic/eval_mic_8
```

### 测评参数解释

`CUDA_VISIBLE_DEVICES=0`

测评和模型 profile 使用第 0 张 GPU。

`python -u evaluation_fixed.py`

启动统一测评脚本。这个脚本负责计算 PESQ、STOI、SDR、SI-SDR，并可统计参数量和计算量。

`--dataset_root /data/lizhe/SH_data/Mic8_2s_gpurir`

数据集根目录。脚本会从这里找到 mix、clean reference 和 wav_scp。

`--prediction_path /data/lizhe/SH_data/Mic8_2s_gpurir/predictions_grouping_inter_mic_8`

推理阶段生成的增强语音目录。

`--test_name mic_8`

指定测评 8 麦测试集。

`--modelpath model_grouping_inter_mse_sisdr_stft_8mic`

模型目录，用于读取权重并统计参数量/计算量。

`--model_name model_best.pth`

用于 profile 的权重文件名。

`--profile_model`

开启 MACs/FLOPs 估计。不开这个参数时，只统计音频指标和参数量。

`--save_dir model_grouping_inter_mse_sisdr_stft_8mic/eval_mic_8`

测评结果保存目录。

---

## 4. 测评输出

测评完成后会输出并保存：

```text
PESQ mix / est / improvement
STOI mix / est / improvement
SDR mix / est / improvement
SI-SDR mix / est / improvement
parameters_total
parameters_trainable
parameters_frozen
MACs / FLOPs approximate, if --profile_model is enabled
```

保存文件包括：

```text
mic_8_detail_metrics.csv
mic_8_summary_metrics.csv
mic_8_metrics.mat
```
