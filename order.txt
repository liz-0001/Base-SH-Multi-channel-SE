# grouping-inter-sds 分支运行指令

本分支默认启用：

```text
order-wise SH grouping
+ ADFS-style high-low correlation guidance
+ adjacent-order interaction
```

命令中不需要写 `--enable_order_grouping`、`--enable_adjacent_interaction` 或 `--enable_high_low_guidance`。这些模块在本分支中默认启动。

---

## 1. 训练指令

```bash
python -u train.py \
  --gpus 0,1,2,3 \
  --loss_type mse_sisdr_stft \
  --sisdr_weight 0.01 \
  --stft_weight 0.5 \
  --num_epoch 100 \
  --batch_size 8 \
  --num_worker 4 \
  --lr 1e-3 \
  --model_dir model_grouping_inter_adfs_mse_sisdr_stft_8mic
```

### 参数解释

`python -u train.py`

启动训练脚本，`-u` 让日志实时输出。

`--gpus 0,1,2,3`

使用 4 张 GPU 训练。如果显存不足，可以改成 `--gpus 0,1` 或 `--gpus 0`。

`--loss_type mse_sisdr_stft`

使用组合 loss：MSE + SI-SDR loss + STFT loss。

`--sisdr_weight 0.01`

SI-SDR loss 权重。

`--stft_weight 0.5`

STFT loss 权重。

`--num_epoch 100`

最大训练轮数。

`--batch_size 8`

全局 batch size。

`--num_worker 4`

DataLoader worker 数。

`--lr 1e-3`

初始学习率。

`--model_dir model_grouping_inter_adfs_mse_sisdr_stft_8mic`

保存权重、训练日志、训练配置和指标的目录。最优权重保存为：

```text
model_grouping_inter_adfs_mse_sisdr_stft_8mic/model_best.pth
```

---

## 2. 推理指令

```bash
CUDA_VISIBLE_DEVICES=0 python -u inference.py \
  --modelpath model_grouping_inter_adfs_mse_sisdr_stft_8mic \
  --model_name model_best.pth \
  --test_name mic_8 \
  --mic_prefix mic \
  --prediction_path /data/lizhe/SH_data/Mic8_2s_gpurir/predictions_grouping_inter_adfs_mic_8
```

### 参数解释

`CUDA_VISIBLE_DEVICES=0`

推理使用第 0 张 GPU。

`--modelpath model_grouping_inter_adfs_mse_sisdr_stft_8mic`

模型权重所在目录。

`--model_name model_best.pth`

读取验证集最优权重。

`--test_name mic_8`

使用 8 麦测试集。

`--mic_prefix mic`

测试 MIC 文件名前缀。你的测试文件类似 `mic_576_0.7.npy`，所以这里写 `mic`。

`--prediction_path /data/lizhe/SH_data/Mic8_2s_gpurir/predictions_grouping_inter_adfs_mic_8`

增强语音保存目录。

## 3. 测评指令

```bash
CUDA_VISIBLE_DEVICES=0 python -u evaluation_fixed.py \
  --dataset_root /data/lizhe/SH_data/Mic8_2s_gpurir \
  --prediction_path /data/lizhe/SH_data/Mic8_2s_gpurir/predictions_grouping_inter_adfs_mic_8 \
  --test_name mic_8 \
  --modelpath model_grouping_inter_adfs_mse_sisdr_stft_8mic \
  --model_name model_best.pth \
  --profile_model \
  --save_dir model_grouping_inter_adfs_mse_sisdr_stft_8mic/eval_mic_8
```

### 参数解释

`--dataset_root /data/lizhe/SH_data/Mic8_2s_gpurir`

数据集根目录。

`--prediction_path /data/lizhe/SH_data/Mic8_2s_gpurir/predictions_grouping_inter_adfs_mic_8`

推理得到的增强语音目录。

`--test_name mic_8`

测评 8 麦测试集。

`--modelpath model_grouping_inter_adfs_mse_sisdr_stft_8mic`

用于参数量和计算量统计的模型目录。

`--model_name model_best.pth`

用于 profile 的权重文件。

`--profile_model`

开启 MACs/FLOPs 估计。

`--save_dir model_grouping_inter_adfs_mse_sisdr_stft_8mic/eval_mic_8`

测评结果保存目录。

## 4. shape test

在服务器训练环境中运行：

```bash
python scripts/test_order_grouping_shape.py
```

用于检查：

```text
order widths = [1, 3, 5, 7]
ADFS-style high-low guidance 后每阶 shape 不变
adjacent interaction 后每阶 shape 不变
concat + fuse 后能回到 emb_dim
```

python inference.py \
  --gpus 0 \
  --file_path /data/lizhe/SH_data/Mic8_2s_gpurir \
